The originals are auto-traced bitmaps (~1100 paths, ~800 unique fills each). Each fill is reclassified by HSL — chromatic oranges/reds map to the Mova crimson ramp at the same luminance; grays map to the warm-neutral ramp; the off-white sheet is dropped to fill="none". Upper luminance is clipped at 0.86 so highlights don't bleed to white. Each icon ships in two variants: muscle-*.svg for light surfaces and muscle-*-dark.svg for dark surfaces, where the warm-gray body luminance is inverted while crimson highlights stay constant.
